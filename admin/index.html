Masuk dengan GitHub

  1. Buka github.com → Fine-grained token
  2. Repository access → Only select repositories → natsutamura/natsu-linktree
  3. Permissions → Contents: Read and write (itu saja)
  4. Generate, copy token (github_pat_…), tempel di bawah

Token tidak dikirim ke mana pun selain api.github.com. Kalau disimpan, hanya tersimpan di localStorage browser ini — jangan pakai di komputer bersama. Kalau token bocor, revoke di GitHub lalu buat baru.
